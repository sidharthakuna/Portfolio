# ⚙ Running Locally

Clone Repository

```bash
git clone https://github.com/sidharthakuna/Portfolio.git
```

Go into the folder

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Run locally

```bash
npm run dev
```

Production build

```bash
npm run build
```
