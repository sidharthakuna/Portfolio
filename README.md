# ⚙️ Running Locally

Clone the repository

```bash
git clone https://github.com/sidharthakuna/Portfolio.git
```

Move into the project

```bash
cd Portfolio
```

Install dependencies

```bash
npm install
```

Run the development server

```bash
npm run dev
```

Build for production

```bash
npm run build
```
